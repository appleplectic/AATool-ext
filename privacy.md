# AA Overlay Privacy Policy
The extension collects as little as possible and nothing is sold.

## What we collect

Viewers: the channel ID of the stream being watched, sent when the overlay loads; display preferences (view, size, scroll speed, folded rows); web request info (not stored: IP address/browser).

Streamers: channel ID, publish key, overlay settings, gameplay progress sent by AATool, statistics when a run is finished.

Twitch hosts extension files; server is ran locally. Nothing else is stored.

## Changes

Any changes will be posted here and the date will be updated.
